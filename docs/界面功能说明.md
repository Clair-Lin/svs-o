# SVS签名验签1.8.0 原型 — 界面功能说明

## 文档范围

本项目为原型：用于演示界面布局与交互流程；列表与图表多为静态或本地模拟数据。

本文仅描述当前侧栏菜单中已展示的界面。 

---

## 一、设备资源（监控总览）

**定位**：集中查看设备与网络运行态势、资源占用及业务侧统计示意。

**系统状态与资源：**修改界面布局

业务统计：新增业务统计模块

| 能力 | 说明 |
|------|------|
| 数据统计 | 展示证书数量、应用实体数量、并发连接数等指标； |
| 业务数据 | 支持按预设时间或自定义日期范围查看签名、验签、制作信封、解信封的成功/失败/合计数量，<br />部分项（签名业务、验签业务）提供 P1/P7 等明细悬浮说明。 |

---

## 二、密钥管理

**定位**：在同一入口下通过 **Tab** 区分两套规范语境——**签名验签服务器（GM/T 0029）** 与 **通用密码服务接口（GM/T 0019）**

### 2.1 签名验签服务器（0029）增加部分

| 能力 | 说明 |
|------|------|
| 算法与用途 | 支持 SM2、RSA、SM4、3DES、AES 等；<br />**密钥用途、密钥长度随算法变化（如签名验签 / 加密解密及组合规则）。**<br />SM2-256；RSA-2048；SM4-128；3DES-168；AES-128 |

### 2.2 通用密码服务接口（0019）（新增界面）

| 能力 | 说明 |
|------|------|
| 条件查询 | 按密钥 ID、密码算法、密钥用途、添加时间范围等筛选；支持重置条件。（与0029界面相同） |
| 列表浏览 | 表格展示密钥索引、密钥 ID、密钥算法、密钥用途、是否可导出、添加时间、操作列 |
| **生成密钥** | 生成密钥表单如原型所示，**密钥用途、密钥长度根据密钥类型不相同** |
|              | 恢复密钥、行内操作、密钥算法、密钥用途列、操作（与0029界面列相同） |
| 是否可导出 | **是否可导出**，展示为 **是** 或 **否**。 |

## 五、一键检测

**定位**：模拟对**服务接口**与**加密卡**的健康检查流程，并展示汇总与明细结果。

| 能力 | 说明 |
|------|------|
| 前置提示 | 在「检测方式」上方提示：检测前需上传 **CA 根证**、**用户证书**；若因证书问题导致接口异常，将提示重新上传后再检。 |
| 证书类异常提示 | 当证书相关接口检测为异常时，结果区顶部展示 **「未检测到证书，请重新上传。」**；<br />对应明细行下同步展示该说明。 |
| 检测范围 | 全部检测、服务接口检测、加密卡检测。 |
| 执行过程 | 开始检查后展示进度与阶段文案。 |
| 结果展示 | 汇总整体状态及检测项数量统计（正常/警告/异常）；<br />展示完成时间、检测对象摘要；服务接口与加密卡分类折叠查看明细（如接口地址、状态等）。 |
| 导出 | 提供导出报告入口。 |
