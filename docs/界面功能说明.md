|              | 恢复密钥、行内操作、密钥算法、密钥用途列、操作（与0029界面列相同） |

## 五、证书管理搜索

**定位**：CA 根证（或同类证书管理）列表页的筛选与列表展示规则（与原型「CA 根证」页一致）。

### 5.1 筛选区

```
CA名称：    [ 请输入CA名称 ]
DN：        [ DN模糊查询：忽略空格，可用空格或逗号分隔多关键字 ]
状态：        [ 下拉：全部 / 未知 / 正常 / 已过期 / 已吊销 / 未生效 ]
生效开始时间：[ 日期 ]   生效结束时间：[ 日期 ]
过期开始时间：[ 日期 ]   过期结束时间：[ 日期 ]
[ 查询 ]  [ 重置 ]
```

### 5.2 DN 搜索规则

- 支持模糊匹配，**忽略空格**。
- 可用**空格或逗号**分隔多关键字，多关键字之间为 **AND** 关系。
- 匹配目标为证书的 **Subject DN**（列表中的 CA 证书 DN 字符串）。

### 5.3 有效期搜索规则

生效、过期各用**两个独立日期控件**（生效开始 / 生效结束、过期开始 / 过期结束），不再使用单个「日期范围」控件：

- **生效（NotBefore）**：仅填「生效开始时间」时筛选 `notBefore ≥ 开始`；仅填「生效结束时间」时筛选 `notBefore ≤ 结束`；**两端都填**时为闭区间（若开始晚于结束，按区间取 min/max 仍作闭区间处理）。两端都不填则该维度不参与筛选。
- **过期（NotAfter）**：与上同理，对应 `notAfter`。
- 生效条件与过期条件、以及 CA 名称、DN、状态等之间均为 **AND**。

### 5.4 状态定义

| 状态     | 判定条件            | 列表显示                |
| -------- | ------------------- | ----------------------- |
| 正常     | 距过期 > 90 天      | 黑色文字                |
| 即将过期 | 0 < 距过期 ≤ 90 天  | 橙色文字 + 剩余天数提示 |
| 已过期   | 当前时间 > 过期时间 | 红色文字                |

（实现说明：到期当日若按「日」比较尚未超过过期日，剩余天数可为 0，界面仍归入「即将过期」并提示「剩 0 天」，避免与「正常」冲突。）

### 5.5 列表字段

| 字段         | 说明 |
| ------------ | ---- |
| CA 名称      | CA 唯一标识 |
| CA 描述      | CA 用途说明 |
| CA 证书(DN)  | 证书 DN 字符串 |
| 生效时间     | NotBefore，格式 `YYYY-MM-DD` |
| 过期时间     | NotAfter，格式 `YYYY-MM-DD` |
| 状态         | 正常 / 即将过期(剩 XX 天) / 已过期 |
| 操作         | 上传下级证书、配置 CRL、配置 OCSP、删除 |

### 5.6 状态与筛选组合逻辑

- 状态筛选与 **CA 名称、DN、生效时间范围、过期时间范围** 之间均为 **AND**。
- 选择 **「即将过期」** 时，等价于在过期时间上自动追加条件：**过期日期落在「当前日期～当前日期+90 天」**（与 5.4 中「即将过期」语义一致）。若用户**同时填写**了「过期时间」手动范围，则与上述区间取 **交集**，以缩小结果集。

## 六、一键检测

**定位**：模拟对**服务接口**与**加密卡**的健康检查流程，并展示汇总与明细结果。

| 能力 | 说明 |
|------|------|
| 前置提示 | 在「检测方式」上方提示：检测前需上传 **CA 根证**、**用户证书**；若因证书问题导致接口异常，将提示重新上传后再检。 |
| 证书类异常提示 | 当证书相关接口检测为异常时，结果区顶部展示 **「未检测到证书，请重新上传。」**；<br />对应明细行下同步展示该说明。 |
| 检测范围 | 全部检测、服务接口检测、加密卡检测。 |
| 执行过程 | 开始检查后展示进度与阶段文案。 |
| 结果展示 | 汇总整体状态及检测项数量统计（正常/警告/异常）；<br />展示完成时间、检测对象摘要；服务接口与加密卡分类折叠查看明细（如接口地址、状态等）。 |
| 导出 | 提供导出报告入口。 |
